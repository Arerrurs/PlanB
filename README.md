# Мудрость дня — итоговая сборка v9

## Что есть в этой версии
- главная карточка с лайком, дизлайком, копированием и шарингом
- личный кабинет с настройками, любимыми и не любимыми цитатами
- смена светлой/тёмной темы
- отдельные акцентные цвета для светлой и тёмной темы
- редактирование почты и пароля из кабинета
- статистика по самой лайкнутой и самой дизлайкнутой цитате по нажатию на иконку книги
- админка с редактированием цитат, сортировкой, пользователями и деталями голосов
- favicon сайта

## Файл конфигурации
В `js/config.js` должны быть:

```js
export const SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co';
export const SUPABASE_ANON_KEY = 'sb_publishable_...';
```

## Как выдать себе роль admin
```sql
update profiles
set role = 'admin'
where email = 'твоя_почта';
```

## Что важно вручную настроить в Supabase
### Убрать подтверждение почты
1. Открой **Authentication → Sign In / Providers**.
2. Выбери **Email**.
3. Выключи **Confirm email**.

### Настроить правильный адрес сайта
Открой **Authentication → URL Configuration** и поставь:
- **Site URL**: `https://arerrurs.github.io/PlanB/`
- **Redirect URLs**: `https://arerrurs.github.io/PlanB/*`

## После замены файлов
Сделай жёсткое обновление страницы.
- ПК: `Ctrl + F5`
- Телефон: открыть сайт в приватной вкладке или очистить данные сайта


## Важно про смену почты
В статической версии на GitHub Pages почту нельзя менять мгновенно и без письма-подтверждения. Клиентский `supabase.auth.updateUser({ email })` запускает подтверждение, а прямое изменение без подтверждения требует server-side Admin API с `service_role`, который нельзя класть в браузер.
